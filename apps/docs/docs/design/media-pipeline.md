# 媒体管线

媒体适配器的输出必须先通过 `MediaItem` Schema，React 层不得直接理解 BirdPaper 或 Konachan 的原始 JSON。媒体 URL、预览图、类型、尺寸与来源标识是跨层唯一契约。

每次加载生成新的会话令牌和 `AbortController`：

1. 取消上一请求；
2. 记录本次令牌；
3. 调用选中源；
4. 只在令牌仍为当前值时提交结果；
5. 将错误转成播放器状态，而不是由组件各自捕获。

这一模型让换源、下一页和自动播放共享同一并发语义。

## 图片预取

首个 Konachan 页面由 RSC 获取。HTML 对当前图片输出高优先级 preload，对播放列表中的下一张图片输出低优先级 preload。客户端播放器同时维护一个有容量上限的图片预加载缓存：游标或列表变化时只预取紧邻的下一张图片，重复 URL 共享同一请求，并在加载后异步请求解码。

缓存状态不进入领域会话。切换媒体时，React 适配层重新查询缓存；若当前图片已经就绪，MediaStage 立即显示并完成背景组件的加载信号，否则仍以真实 `load`/`error` 事件结算。这样分页数据预取、图片字节缓存和组件生命周期保持为三个独立层次。
